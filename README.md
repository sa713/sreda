# Среда ИИ

Русскоязычный учебный портал о применении ИИ в работе. Каталог и страницы
материалов собираются в статический HTML, который раздаёт Nginx.
Кнопка «Было полезно» и счётчики обращаются к сервису статистики внутри Compose.

## Первый запуск на Debian 13

Нужны Git, Docker Engine с плагином Compose и Python 3 для проверки через HTTP.
Команды предполагают, что текущий пользователь может писать в `/opt` и
запускать Docker.

Проверьте, свободен ли порт 8096. Если команда покажет слушающий процесс,
выберите другой порт и укажите его в `.env`.

```sh
ss -H -ltn 'sport = :8096'
git clone https://github.com/sa713/sreda.git /opt/sreda
cd /opt/sreda
printf 'SREDA_BIND=0.0.0.0\nSREDA_PORT=8096\n' > .env
docker compose up -d --build --wait
```

При запуске по IP откройте `http://IP_СЕРВЕРА:8096/`. Доступность снаружи
зависит от сетевых правил сервера и провайдера.

Если порталу назначен домен и действующий Caddy работает на хосте или
использует сеть хоста, укажите `SREDA_BIND=127.0.0.1` в `.env` и добавьте
в действующий Caddyfile блок с назначенным доменом:

```caddyfile
sreda.example.org {
    reverse_proxy 127.0.0.1:8096
}
```

Если Caddy использует изолированную Docker-сеть, подключите оба сервиса
к общей сети и укажите в Caddy upstream по сетевому имени портала и
внутреннему порту 80. Перед применением проверьте действующую конфигурацию Caddy.

## Обновление и проверка

```sh
cd /opt/sreda
git pull --ff-only
docker compose up -d --build --wait
docker compose ps
python3 check.py http://127.0.0.1:8096
```

Замените 8096 выбранным портом. Проверка проходит навигацию по каталогу,
каждую страницу по её адресу, повторную загрузку, ссылки возврата, ответ 404
и наличие счётчиков для всех карточек.
Просмотр журнала: `docker compose logs --tail=50 portal`.

## Просмотры и отметки

Просмотр засчитывается при открытии или обновлении страницы материала в браузере.
Отметка «Было полезно» сохраняется для текущего браузера через анонимный cookie.
Повторное нажатие снимает отметку. Общие числа хранятся в SQLite в томе
`sreda_metrics-data` и сохраняются при пересборке контейнеров. Удаление тома
сбрасывает статистику.

## Как редактировать каталог

[Карта XMind](https://app.xmind.com/7nUgZ7zp) задаёт структуру и порядок.
В [data/catalog.json](data/catalog.json) порядок элементов определяет
порядок разделов и карточек. У раздела есть заголовок `title` и короткая
подпись в навигации `nav`. Поле `id` задаёт ссылку на раздел на главной.
У карточки есть название, описание и постоянный адрес `url`.
Сохраните `id` и `url` при изменении заголовков и порядка.

Чтобы опубликовать текст по адресу `/materials/how-to-prompt/`, добавьте
`content/how-to-prompt.md` и пересоберите образ. Название страницы берётся
из каталога, поэтому внутри Markdown начинайте подзаголовки с `##`.
Можно использовать списки, ссылки, таблицы, цитаты и блоки кода.
Изображения кладите в `static/` и указывайте путь вида `/assets/image.png`.
Для страниц без соответствующего файла сайт показывает «Материал готовится».

## Локальная сборка

```sh
python3 build.py
python3 -m http.server --bind 127.0.0.1 --directory dist 8096
```

Локальный HTTP-сервер показывает каталог и статьи без интерактивных счётчиков.
Для полной проверки запустите Docker Compose.
Для сборки с Markdown-файлами нужен Pandoc. В Docker он установлен в сборочном
слое.
